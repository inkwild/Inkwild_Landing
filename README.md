# Inkwild site

The website for **Inkwild: Hunter's Journal**: a home page and the privacy policy the game links to from Settings.
Plain HTML and CSS in the field-journal look; both fonts are served from `fonts/` (SIL OFL 1.1), so the pages load
nothing from other sites.

Published with GitHub Pages from `main`, root folder. When the game is on Google Play, replace "Coming soon to Google
Play" on the home page with the store link. Keep the privacy policy's partner list in step with the CAS setup.
